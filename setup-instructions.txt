SETUP INSTRUCTIONS
==================

STEP 2: DATABASE SETUP
----------------------

EASIEST OPTION (Recommended):
1. Go to https://supabase.com
2. Sign up and create a new project
3. Go to Settings → Database
4. Copy the "Connection string" (URI format)
5. Paste it as DATABASE_URL in your .env file

STEP 4: ENVIRONMENT VARIABLES
-------------------------------

1. Create .env file:
   cp env.example .env

2. Open .env and update:
   - DATABASE_URL: Your PostgreSQL connection string
   - NEXTAUTH_SECRET: Already generated (T8gB6jKGm9up7KKbCecR9whdpkPjRnE+4COpSWJRzbk=)
   - NEXTAUTH_URL: http://localhost:3000 (already set)
   - APP_URL: http://localhost:3000 (already set)

3. Then run:
   npx prisma generate
   npx prisma migrate dev --name init

4. Start server:
   npm run dev

See QUICK_SETUP.md for detailed instructions!
